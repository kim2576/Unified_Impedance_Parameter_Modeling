# Figures predate the velocity-input change

The PNG figures in this directory were bundled with the original uploaded package and were **not generated by this updated source code**. They reflect the previous calculation of velocity by finite differences of the modeled joint-angle surface. Run `evaluate_and_plot.m` with `angular_velocity_variant = "original"` (or `"norm"`) to regenerate figures with the new preprocessed-velocity input.
