# Input data

This directory contains the biomechanical-model inputs used by the impedance-parameterization pipeline.

Two MATLAB files are expected:

- `RBF_models.mat`, containing `RBF_model_full`
- `AB_refs.mat`, containing `target_biomechanics_total`

`RBF_model_full` contains the continuous RBF-unified knee and ankle biomechanics evaluated across the terrain-slope and normalized-phase domain, **including independently modeled angular-velocity surfaces**. Required fields for this pipeline are `knee_angle_dot_stance`, `ankle_angle_dot_stance`, and their `_norm` variants; each provides `RBF_in_full_domain` in phase × slope orientation (101 × 71). `target_biomechanics_total` contains the discrete able-bodied reference trajectories used for reconstruction evaluation and plotting.

These files are generated by the preceding continuous biomechanics-modeling framework and are loaded by:

```matlab
inputs = load_impedance_inputs( ...
    "data/RBF_models.mat", ...
    "data/AB_refs.mat", ...
    AngularVelocityVariant="original"); % or "norm"
```

The variable names above are part of the expected interface and should be preserved unless `load_impedance_inputs.m` is updated accordingly.

The first 100 phase samples of the selected RBF angular-velocity surface are
used directly (71 × 100 after transpose). Angular velocity therefore remains an
independently modeled biomechanical input to the impedance regression.
